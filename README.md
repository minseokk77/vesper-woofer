# 🔊 Vesper Woofer

**Vesper Woofer** (구 Woofer Sync)는 Vesper DSP와 완벽한 시너지를 발휘하는 **서브우퍼 및 베이스(Bass) 채널 전용 딜레이/크로스오버 동기화 유틸리티**입니다.
메인 스피커(DSP)와의 미세한 위상차와 딜레이를 완벽하게 보정하여 룸 어쿠스틱 환경에서 궁극의 저역대 일체감을 제공합니다.

## ✨ 주요 기능

- ⏱️ **초정밀 딜레이 싱크(Delay Sync)**
  - 메인 스피커와의 물리적 거리 차이로 인해 발생하는 위상/시간차를 밀리초 단위로 정밀하게 보정
- 🎛️ **크로스오버 필터링 및 서브소닉 제어**
  - 원활한 저역 주파수 분리를 위한 맞춤형 컷오프(Cut-off) 필터 지원
- 🚀 **Vesper 생태계 통합**
  - [Vesper DSP](https://github.com/minseokk7/vesper-dsp)와 함께 구동 시 더욱 강력하고 유연한 데스크톱 오디오 청취 환경 완성

## 📥 다운로드 및 설치

Vesper Woofer의 최신 설치 파일은 우측의 **[Releases](https://github.com/minseokk7/vesper-woofer/releases)** 탭에서 다운로드하실 수 있습니다.
